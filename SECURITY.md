# Security Policy

## Reporting a Vulnerability

Please don't open a public issue for a security vulnerability. Instead, use GitHub's private vulnerability reporting for this repository:

**[Report a vulnerability](https://github.com/RetiredOnMyTerms/UnitsOfTime/security/advisories/new)** (Security tab → Report a vulnerability)

This opens a private advisory visible only to the maintainer until it's resolved.

## In scope

- Vulnerabilities in this repository's code
- Vulnerabilities in this project's dependencies

## Out of scope

- Social engineering
- Physical security
- Anything requiring access this project doesn't grant (there's no backend or hosted deployment yet — everything runs client-side with `localStorage`)

## Supported versions

This project doesn't yet have tagged releases; only the `main` branch is supported.
